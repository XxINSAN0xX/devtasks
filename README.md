# DevTasks

Aplicação web para gerenciamento de tarefas desenvolvida como projeto de estudo e portfólio.

## 🚀 Sobre o projeto

O DevTasks permite que o usuário crie, organize e acompanhe suas tarefas de forma simples.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro, com armazenamento dos dados no navegador através do LocalStorage.

## ✨ Funcionalidades

- Criar tarefas
- Definir prioridade
- Marcar tarefas como concluídas
- Excluir tarefas
- Filtrar tarefas
- Visualizar estatísticas
- Salvar tarefas automaticamente no navegador
- Layout responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
